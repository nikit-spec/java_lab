## Задача 7
### Текст задачи

Метод принимает левую и правую границу (`a` и `b`) некоторого числового диапазона. Необходимо реализовать метод таким образом, чтобы он возвращал `true`, если `num` входит в указанный диапазон (включая границы). Обратите внимание, что отношение `a` и `b` заранее неизвестно: неясно, кто из них больше, а кто меньше.

Пример 1:\
a = `5`, b = `1`, num = `3`\

2. Проверить диапазон при обратном порядке границ: `num >= b && num <= a`.
3. Если выполнено хотя бы одно из условий - вернуть `true`, иначе - `false`.

Пример 1:\
x = `5`\
результат: `true`\
Пример 2:\
x = `8`\
результат: `false`\
Пример 3:\
x = `15`\

### Алгоритм решения
1. Проверить делимость числа `x` на 3 (`x % 3 == 0`) - сохранить результат в переменную `div3`.
2. Проверить делимость числа `x` на 5 (`x % 5 == 0`) - сохранить результат в переменную `div5`.
3. Если `div3` и `div5` одновременно истинны - вернуть `false`.
4. Иначе, если истинно хотя бы одно из условий - вернуть `true`.
5. В противном случае вернуть `false`.

## Задача 3
### Текст задачи
**Поиск максимального.**
Дана сигнатура метода: `public int maxAbs(int[] arr);`
Необходимо реализовать метод таким образом, чтобы он возвращал наибольшее по модулю (то есть без учёта знака) значение массива `arr`.

Пример:\
arr = `[1, -2, -7, 4, 2, 2, 5]`\
результат: `-7`

### Алгоритм решения

3. Если `abs(arr[i]) > abs(max)` - присвоить `max = arr[i]`.
4. Вернуть найденный элемент `max` с его исходным знаком.

## Задача 5
### Текст задачи
**Добавление массива в массив.**
Дана сигнатура метода: `public int[] add(int[] arr, int[] ins, int pos);`
Необходимо реализовать метод таким образом, чтобы он возвращал новый массив, который содержит все элементы массива `arr`, однако в позицию `pos` будут вставлены значения массива `ins`.

Пример:\
arr = `[1, 2, 3, 4, 5]`\
ins = `[7, 8, 9]`\
pos = `3`\
результат: `[1, 2, 3, 7, 8, 9, 4, 5]`

### Алгоритм решения
1. Создать новый массив `result` длиной `arr.length + ins.length`.
2. Скопировать элементы `arr` до позиции `pos` в начало `result`.
3. Скопировать элементы `ins` в `result`, начиная с позиции `pos`.
4. Скопировать оставшиеся элементы `arr`, сдвинув их на `ins.length` позиций.
5. Вернуть `result`.
